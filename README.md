# anim-studio

Code-only animation. No hand drawing, no editors: every frame is generated by scripts.
Two engines, one ffmpeg finish.

| Style | Engine | Where it runs | Cost of 10 s |
|---|---|---|---|
| **3D low-poly** (Fern-style island, Assassin-style rooftop) | Blender 4.2 Cycles, scripted in Python | GitHub Actions (free runners) | ~8 jobs x ~20 min |
| **Flat vector stickman** (hoodie character, sunset palettes, rim light) | Pure shapes: Python + Pillow + numpy | Any machine, no GPU, no display | ~30 s |

## 1. 3D engine (`scenes/`, `.github/workflows/render.yml`, `scripts/assemble.sh`)

How the two sample clips were made:

1. `scenes/common.py` is a tiny mesh toolkit (`M.box/cyl/sphere/tri/quad`) with per-face vertex colours, so the whole look is flat low-poly shading. It also has the shared sky, sun, camera and render setup, plus `Dyn` (rebuild a mesh each frame: birds, embers) and `Cloth` (grid driven by a function of time: cloaks, flags).
2. `scenes/assassin.py` / `scenes/fern.py` build a scene procedurally (hundreds of buildings, terrain from fbm noise, trees, village, ship...) and define an `update(frame)` that moves the camera and animated parts.
3. The workflow downloads official Blender 4.2.3, concatenates `common.py + <scene>.py` and renders **8 shards in parallel** (frame f goes to shard `f % 8`), 24 fps, 1280x720, Cycles + OpenImageDenoise.
4. The `assemble` job stitches frames with ffmpeg (grade, vignette, grain, letterbox bars, title text, fades) and pushes the result to the `out` branch (`out/<scene>/<scene>.mp4`).

Run it: Actions > render > Run workflow. `preview=1` gives a 4-frame contact sheet in about 2 minutes; `preview=0` renders the full 10 s. `scenes` is a JSON list, e.g. `["fern"]`.

## 2. Flat 2D engine (`flat2d/flat.py`)

`python3 flat2d/flat.py out.mp4` renders `flat_bus` (misses the bus, then rides it). `python3 flat2d/flat.py out.mp4 p` renders 7 preview frames only.

How it works:

- **Backgrounds**: vertical gradients (`vgrad`), a sun glow + translucent ray polygons, blurred cloud ellipses, silhouette houses, wires as sagging polylines. Built once per scene and cached.
- **Character** (`draw_char`): a rig made only of shapes. Head circle + hood ellipse, tapered polygons for hoodie, arms and legs, rounded rectangle shoes, arc smile, ellipse eyes. Limbs use 2-bone forward kinematics (`fk`): you give angles (thigh/shin, upper arm/forearm) and the pose follows. `run_pose(phase, amp)` is a run cycle, `grounded_hip` plants the lowest foot on the floor. The gold edge is a rim light made by offsetting the character's alpha and subtracting.
- **Post** (`post`): downscale 1920x1080 to 1280x720 (free anti-aliasing), vignette, film grain, letterbox, HUD pill (`DAY 1 - 6 MPH`), fades.
- Frames are piped straight into ffmpeg, so nothing touches disk.

To make a new shot: write `frame_X(t)` that returns an image for time `t`, add it to the timeline in `main()`.

## 3. Making ~10 minute videos (e.g. Greek mythology)

Be realistic about cost: 10 min = 14,400 frames. The 3D engine is roughly 160 runner-minutes per 10 s, so a full 10 min in 3D would be around 160 runner-hours. Not viable on free runners. The flat 2D engine is about 30 s per 10 s, so about 30 min for 10 min of footage on one machine.

Plan:

1. **Script first.** Write the narration (~1,400 words for 10 min), split into 40-60 shots of 5-15 s each. Put them in a `shots.json`: `{scene, duration, characters, camera, caption}`.
2. **Scene library.** One function per location (Mount Olympus, temple, sea at dawn, labyrinth, underworld river, battlefield). Each is `bg_x()` cached + `frame_x(t)`.
3. **Cast library.** Reuse `draw_char` with different hood colours, hair, props (spear, shield, laurel, wings as extra polygons). Gods can be taller (`S`), with a glow layer.
4. **Camera moves in 2D**: slow zoom/pan by cropping the 1920x1080 frame (render large, crop to 1280x720), parallax by moving background layers at different speeds.
5. **Render shots in parallel** (one process per shot), then concatenate with ffmpeg `concat` and crossfades.
6. **Voice + music**: TTS or recorded narration, then mix with ffmpeg `amix`. Caption burn-in from the same script.
7. **3D only for hero shots** (title card, establishing flyover of an island or temple) at 5-10 s each, via the Actions workflow, then dropped into the timeline.

## Notes

- Characters are original designs. No copyrighted characters.
- Outputs are 1280x720, 24 fps, no audio unless you add it.
